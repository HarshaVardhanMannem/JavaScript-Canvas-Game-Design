# JavaScript Basics & DOM Manipulation Practice

Welcome to my JavaScript fundamentals practice repository! This collection focuses on strengthening core JavaScript concepts and DOM manipulation skills through building classic arcade games. Each project is designed to reinforce essential programming foundations while creating engaging, interactive experiences.

## 🎯 Learning Objectives

This repository is specifically designed to strengthen **JavaScript fundamentals** and **DOM manipulation** skills:

### **JavaScript Basics Reinforcement**
- **Variables & Data Types** - let, const, strings, numbers, booleans
- **Functions** - Declaration, expressions, parameters, return values
- **Conditionals** - if/else statements, switch cases, logical operators
- **Loops** - for, while, forEach, array iteration
- **Objects & Arrays** - Creation, manipulation, property access
- **Scope & Hoisting** - Understanding variable scope and function behavior

### **DOM Manipulation Mastery**
- **Element Selection** - querySelector, querySelectorAll, getElementById
- **Event Handling** - addEventListener, event objects, keyboard/mouse events
- **Content Manipulation** - innerText, innerHTML, textContent
- **Attribute Control** - classList, setAttribute, getAttribute
- **Dynamic Styling** - style property, CSS class manipulation
- **Element Creation** - createElement, appendChild, removeChild

### **Practical Application**
- **Interactive Games** - Applying concepts through real projects
- **User Input Processing** - Handling clicks, keyboard presses, form data
- **Dynamic Content Updates** - Real-time score updates, game state changes
- **Event-Driven Programming** - Building responsive, interactive applications
